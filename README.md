# 🎓 CampusConnect — College Social Hub

CampusConnect is a cross-platform app for college students and admins to manage events, chat in study groups, and handle lost-and-found reports — all in real-time.

## 🔧 Tech Stack

- **Frontend (Mobile):** React Native (Expo)
- **Frontend (Web):** Next.js + Tailwind CSS
- **Backend:** Firebase (Auth, Firestore, Storage, Functions, FCM)

## 📱 Features

### Mobile App (React Native)

- 👤 Login/Register (Firebase Auth)
- 📅 View upcoming events
- 🔍 Lost & Found
- 💬 Study group chat (Firestore)
- 🔔 Push notifications (FCM)

### Web Dashboard (Next.js)

- 🧑‍💼 Admin login
- ✍️ Post events and announcements
- 🧹 Moderate lost/found items
- 📈 View dashboard stats

## 🔥 Firebase Services

- Firebase Authentication
- Firestore (database)
- Cloud Functions (trigger notifications)
- Firebase Storage (images)
- Firebase Cloud Messaging (push)
